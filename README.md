## 📖 Descrizione
**Pipeline ETL** per dati NASA open source.
- **Extract:** NASA API + CSV (Near Earth Objects, ISS, Mars Rover)
- **Transform:** Pandas (telemetria, coordinate, timestamps)
- **Load:** SQLite Data Warehouse
- **Analytics:** Mission stats, orbite, rover paths

  <br>

**Obiettivo CV:** Data Engineering multi-dominio (Healthcare + Aerospace).

<br>

Sources: NASA API (NeoWs, ISS, Mars Rover) <br>
